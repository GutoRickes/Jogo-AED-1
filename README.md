# Jogo-AED-1
Jogo criado para a disciplina de Algorítmos e Estrutura de Dados 1

A ideia do projeto é recriar de forma simples o clássico jogo do Tetris, com implementação de uma prévia da peça que está por vir e um possível sistema de pontuação.

Semana 1:
- Pesquisas relacionadas a estruturação do código do jogo
- Análise da estruturação do código
- Pesquisa de design visual do jogo

Semana 2:
- Devido sa condições climáticas adversas, atrasou o progresso de desenvolvimento do jogo
